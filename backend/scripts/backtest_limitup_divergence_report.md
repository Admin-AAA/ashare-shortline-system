# 涨停后分歧日低吸（弱转强）— 回测报告（诚实样本外验证 · 负向，不纳入）

> 生成：2026-07-10 第 170 轮 self-improve（T1 策略研发）
> 脚本：`backend/scripts/backtest_limitup_divergence.py`
> 测试：`backend/tests/test_backtest_limitup_divergence.py`（5 passed，含 DB 集成）

## 1. 因子假设（因果机制）

游资封板（T 日涨停）后，次日（T+1，分歧日）常出现「高开 + 冲高回落 + 放量」的换手洗盘；
第三日（T+2，一致日）开盘平开/高开 = 弱转强确认，是二波拉升的经典起点（游资「分歧转一致」）。

- T 日：涨停（limit_up_board.limit_type='U' 且当日涨幅 ≥9.5%）
- T+1（分歧日）：高开 ≥+1%（承接）、收弱（涨幅 ≤+1.5% 且盘中上探）、放量（≥涨停前 8 日均量 1.2 倍）、不破位（最低 ≥ T 最低 ×0.97）
- T+2（一致日）：开盘平开/高开（相对 T+1 收盘 ∈[−1%, +9%)）→ 开盘买入
- 退出：持有 5 日，或止损 −5.7% / 止盈 +9%（再涨停），成本单边 0.07%

**无未来函数**：信号在 T+1 收盘后判定，T+2 开盘买入，仅用 T+1 及之前数据。

## 2. 与现有策略的区分

- 不同于 `limit-up-reseal-relay`（炸板**同日**回封）：本因子是涨停后**隔日**分歧换手。
- 不同于 `backtest_first_limit_up`（低位**首板 + 板块共振**接力）：本因子是**连板/二波**的二次介入。

- 平均胜率 **41.5%**，最小 14.3%，最大 73.3%
- **胜率 >50% 窗口占比仅 16%**
- 平均盈亏比 1.26（>1.4 窗口占 37%），平均净收益 **−0.60%**
- 唯一 73.3% 窗口（04-12~05-12）为离群值，非稳定边缘

## 5. 结论：负向，不纳入实盘

全样本胜率 40.4% < 50%、均净 −0.47%、盈亏比 1.29 < 1.4；滚动窗口仅 16% 胜率 >50%。
该「弱转强」模式**在 2023–2026 A 股数据、扣费后呈净负、regime 依赖噪声**，与第 168 轮
「低位首板接力」同属样本外失效。遵守第一性原理「回测是证明策略不是噪声」——**不采纳**，
不写入 `strategy.yaml`。
