# 龙虎榜机构净买「次日延续」诚实样本外回测报告

**任务类型**: T1 策略研发（因子质量审计 / 诚实样本外验证）
**日期**: 2026-07-21
**脚本**: `scripts/backtest_dragon_tiger_follow.py`
**结论**: **净负，不纳入 strategy.yaml**；反向价值 = 为「禁止放宽 dragon-tiger 触发条件」提供实证护栏。

---

## 1. 因子定义与因果假设

个股登上龙虎榜且机构/席位净买入（`dragon_tiger.net_amount_yi > 0`），代表真实资金主动接入。
假设：真聪明钱净买 = 信息优势方建仓 → 后续交易日更高概率延续上行。
本脚本审计**该信号的预测力结构**（非重复「同日净买即买」的现有策略）。

## 2. 数据现实（关键约束）

| 表 | 覆盖区间 | 行数 |
|---|---|---|
| `dragon_tiger` | **2026-03-23 ~ 2026-07-21（仅 4 个月）** | 5751 |
| `limit_up_board` | 2026-03-23 ~ 2026-07-21（仅 4 个月） | 8533 |
| `daily_kbars` | 2021-05 ~ 2026-07（多年度富数据） | 1.36M |

**结论性约束**：板块/龙虎榜/涨停数据均仅覆盖 2026-03 起 ~4 个月，**无法做跨年度滚动 OOS**
（framework 要求 >50% 滚动窗 >50% 胜率）。本回测只能：
(a) 在可得窗口内看信号稳定性（窗内样本偏小，结论谨慎）；
(b) 按净买强度分桶看单调性（因子预测力结构，不依赖长样本）；
(c) 与同期全市场基准对比，确认 alpha 非市场 beta。

## 3. 回测结果（净成本口径，单边 0.07%）

**全样本**（信号 1490 stock-days / 838 codes，净买≥0.5亿）：

| 指标 | 值 |
|---|---|
| 交易数 n | 754 |
| 净胜率 | **34.6%** |
| 净平均收益 | **-1.14%** |
| 净盈亏比 | **0.76** |
| 最佳 / 最差 | +21.0% / -18.9% |
| 出场分布 | expire 154 / take_profit 230 / stop_loss 369 |

**净买强度分桶（看单调性）**：

| 净买区间（亿） | n | 胜率 | 净均收益 |
|---|---|---|---|
| [0.5, 1.0) | 235 | 28.5% | -2.01% |
| [1.0, 2.0) | 237 | 36.3% | -0.97% |
| [2.0, 5.0) | 201 | 36.3% | -0.98% |
| [5.0, +∞) | 81 | 43.2% | +0.48% |

→ 弱单调（28.5%→43.2% 随净买上升），但**所有桶均 <50% 胜率且净均为负**。

**滚动窗稳定性（每窗 20 交易日）**：**0/20 窗 ≥50% 胜率**，且胜率随时间**下滑**
（25%→23.6%）——典型 regime 漂移净负，非稳定边缘。

**同期市场基准**（信号日全市场 T+1 买入持有 5 日）：n 大，胜率/均收益与信号组同量级偏低，
说明信号组并未显著跑赢市场 beta（无独立 alpha）。

## 4. 采纳判定

| 门槛 | 实测 | 达标 |
|---|---|---|
| 净胜率 > 50% | 34.6% | ❌ |
| 净盈亏比 ≥ 1.4 | 0.76 | ❌ |
| 滚动窗 ≥50% >50% 胜率 | 0/20 | ❌ |

**判定：净负，丢弃。不写入 strategy.yaml。**

## 5. 反向价值（防过拟合护栏）

实盘 `dragon-tiger-smart-money` 策略前瞻胜率 **72.7%**，但其回测/实盘信号均要求
**涨停日上下文 + 板块强度 + 特定聪明钱定义**的复合过滤。本回测证明：

> **龙虎榜净买「次日」信号本身无稳健正边缘**（全样本 34.6%、0/20 滚动窗达标、所有净买桶净负）。
> 现有策略的 72.7% 胜率来自其**复合过滤**，而非净买强度本身。

**因此明确禁止**：将 `dragon-tiger-smart-money` 的触发条件放宽到「任意净买日」——
那会把本回测证伪的净负票注入候选池，**损害 D 项（回测胜率/盈亏比/最大亏损）**。
放宽触发必须以「放宽后子集的诚实 OOS 回测达标」为前提，本因子证据不支持。
