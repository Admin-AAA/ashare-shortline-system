# 低位首板接力 — 诚实样本外回测报告（T1 策略研发）

> 生成日期：2026-07-10 ｜ 回测脚本：`scripts/backtest_first_limit_up.py`
> 数据：本地 `ashare_workbench` MySQL — `daily_kbars`(1.2M 行, 2021–2026) + `limit_up_board`(56.6K 行)
> 成本口径：单边 0.07%（佣金万1 + 印花税0.05%卖出 + 滑点代理），与 T2 净成本口径一致

## 因子定义（因果机制）

- **首板**：个股当日为首次涨停（`limit_times==1`）且前 5 个交易日非涨停（真首板，非连板/回封）。
- **低位**：收盘价处于近 60 日价格区间下 35%（非已大涨的多板高位票）。
- **板块共振**：当日同行业另有 ≥2 只涨停（资金系统性涌入板块，首板是先锋/补涨而非孤立庄股）。
- **交易**：T+1 开盘买入（一字涨停买不到则跳过），持有至 T+3 收盘，或任一日开盘 ≤ -5% 止损。

## 结论（诚实，按第一性原理 #5）

**该因子不通过样本外稳健性检验，不纳入实盘策略。**

- 全样本 54.2% 胜率 ≈ 二项分布 95% CI (40%, 68%)，与 50% 噪声不可区分。
- 滚动窗口仅 **33%** 胜率 >50%，多个窗口 20–40% 且盈亏比 <1；正向窗口全部集中在 2026 春季。
- 样本每窗口仅 2–20 笔，方差极高，统计不可信。
- 与 rounds 163/164 的系统级结论一致：**A 股短线个体因子在 2026 多为噪声/regime 依赖**，不能用全样本虚高胜率误判为 alpha。
