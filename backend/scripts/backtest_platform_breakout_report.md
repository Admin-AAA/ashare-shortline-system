# 平台突破（缩量横盘 + 放量突破）回测报告

> T1 策略研发 / 诚实样本外验证。**结论：净负，不纳入 strategy.yaml。**

## 因子定义
个股在 L=15 日维持窄幅横盘（全幅/均价 ≤12% 且基本水平），期间成交量相对前段明显萎缩
（缩量蓄势 = 供给枯竭），随后以显著放量（≥1.8x 横盘均量）向上突破横盘区上沿（收盘创 L 日
新高）、当日涨幅 3%~9.5%、温和站上 20 日线。属动量延续（momentum continuation），非均值回归——
与 #168/#170/#182 失败的均值回归因子因果方向相反。

## 回测设定
- 区间：2024-01-02 ~ 2026-06-24（597 交易日，5532 个股，125 万 K 线）
- 入场：突破日 T+1 开盘；低开 >1.5% 或高开 ≥9%（一字）跳过
- 持有：T+1..T+5，止损 -5.7% / 止盈 +8% / 到期平仓
- 成本：整笔 round-trip 0.07%（与 production ADDITIONAL_COST_PCT 及 self_check D 项口径一致）
- 指标：**内存从 OHLCV 计算 ma20_calc**（见下「数据质量发现」）

## 滚动窗口 OOS（16 窗口，评测期）
- 平均胜率 **45.2%**，仅 **25%** 窗口 >50% 胜率
- 平均盈亏比 1.83，仅 **31%** 窗口 >1.4
- 均净>0 窗口占比 50%
- **判定：regime 依赖噪声，不满足「胜率>50% 窗口≥50%」门槛**

## 结论
因子在 A 股日线 2024-2026 全样本净负、样本外不稳定，**按第一性原理「回测证伪噪声」直接丢弃**，
不写入 strategy.yaml（守「准确 > 可见」、不为刷数字纳入净负因子）。

## ⚠️ 重大数据质量发现（本轮副产物，影响所有历史回测）
`daily_kbars.ma20` 与 `turnover_rate` 列在 **2024/2025 全为 NULL、2026 也约 88% 缺失**
（实证：2024 49528/49528 缺失，2025 627765/627765 缺失，2026 506954/576554 缺失）。

- **首次跑本因子时直接用 `daily_kbars.ma20` 做「站上 20 日线」过滤 → 历史信号被静默全部杀死，
  1686→仅 128 信号且 100% 挤在 2026**（虚假「因子只在 2026 有效」）。修正为内存计算 ma20_calc
  后信号恢复到跨年份的正常分布（2024/2025/2026 均有）。
- **影响面**：生产 `feature_builder`/`market_data` 用 `_ma(closes,20)` 兜底，**实盘不受影响**；
  但 `stock_matrix_service:294`/`backtest_service:619`/`stock_backtest_service:283` 及 T1 脚本
  （hammer_support / first_limit_up / limitup_divergence）直接读 `bar.ma20` → **所有读该列的历史
  回测/分析在 2024-2025 数据上均被静默污染**。
- **对策**：回测类脚本须**内存从 OHLCV 计算指标**，勿信任 `daily_kbars.ma20`/`turnover_rate`
  的历史值（`scheduler_service:954` 的 K 线指标回填显然只覆盖了近期数据）。
- **建议（本轮未执行，避免范围蔓延 + 风险 DB 写）**：① 重跑 #168/#170/#182 三个 T1 回测，
  用内存指标确认其负向结论是否受此 bug 干扰；② 评估是否补回填 daily_kbars 历史指标列。
