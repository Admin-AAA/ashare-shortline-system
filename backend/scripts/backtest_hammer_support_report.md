# 长下影支撑反转（MA20 锤子线）回测报告

> T1 策略研发 / 诚实样本外验证 — **结论：负向，不纳入实盘**  
> ⚠️ 下方「修正前」数字曾被 daily_kbars 数据坑污染；以 **§修正后** 与 `backtest_reverify_databug_report.md` 为准。

## 因子定义（因果机制）

在「中长期上升趋势」中，短期回调把价格带回到 20 日线（MA20）关键支撑位。测试日 T
当天卖盘把价格打压到 MA20 下方（盘中最低触及支撑），买盘坚决拒绝更低价 —— 形成
「长下影线」（锤子线）。这是「支撑位抛压耗尽 + 资金承接」的经典形态；若支撑有效，
在仍完好的上升趋势里价格向均值回归向上是大概率事件。

信号 = 锤子线（长下影 + 极小上影）∧ 上升趋势中的回调至 MA20 支撑 ∧ 非极端
（涨跌幅 -7%~+6%、成交额≥3亿；换手/量比有真实值时再卡带）∧ 非 ST。
T+1 开盘买入（低开>1.5% 或高开≥9% 跳过），持有 5 日，止损 -5.7% / 止盈 +8%，
单边成本 0.07%。

## 判定：噪声，丢弃（不纳入）——结论 ROBUST

1. 修正后全样本胜率仍 <50%，盈亏比仍 <1.4 达标线。
2. 2026 净负退化 → regime 依赖。
3. **数据坑伪造的是「极稀疏」，不是「不采纳」**——有量后仍是噪声。
4. 与 #168 首板、#170 分歧日低吸、#193 平台突破同属 2023-2026 短线因子 OOS 坍塌区。
