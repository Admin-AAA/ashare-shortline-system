# 弱市强势股确认回撤 Skill Agent

只评估弱市中的“强势股缩量回撤、止跌确认”机会。它不是抄底策略，也不在系统性恐慌日交易。

## 因果链

弱市中，仍有 20 日相对强度的个股更可能承接有限风险偏好；回撤缩量而均线未破，说明抛压收缩；当日小阳或平盘确认后，才在下一交易日开盘试错。

## 必要条件

- 市场 `market_regime == 弱势`，且 `limit_down_count <= 100`
- `chg20 >= 15`、`pos60 >= 50`、`off_high_pct >= -12`
- 当日 `pct` 在 `[0, 3)`：不接当日下跌刀，也不追涨
- `vol5_20 <= 1.1`，且 `support_ma5` 或 `support_ma10` 为真

## 一票否决

1. `limit_down_count > 100`：系统性恐慌，禁入。
2. 趋势破坏：`max_dd20 < -14`。
3. 放量下跌：`vol5_20 >= 1.4` 且 `pct <= 0`。
4. ST、负面公告或过多新闻风险。

## 执行纪律

- 信号收盘后生成，实际入场为下一交易日开盘。
- 持有窗口以 3–5 个交易日验证；若次日低开放量跌破 MA10，退出而非补仓。
- 这是独立策略假设，只有本地历史回放和后续前瞻样本均通过时才可扩大使用。

## Agent 输出约束

输出必须含 `stance` 与 `action`。恐慌日或趋势破坏时，`stance` 为 `veto`，`action` 为“不做”；满足全部确认条件时，`stance` 最多为 `support`，`action` 为“轻仓试错”，不得给出追涨或补仓建议。

## 研究来源

- Chen, Jiang, Li（2012）：中国市场的短期反转在下跌市场更明显，但其研究周期为周/月级，不能直接推出“当天大跌即买”。
- 社区中“强势股缩量回踩、止跌确认”的经验法则只用于提出变量与入场顺序；系统以本地历史、次日开盘模拟来决定是否保留。
