# 高位放量滞涨预警 Skill（命令式）

## 这是什么

一个**命令式（Python）**短线风险预警策略：识别「量在放、价不涨」的顶部信号——
股价已经明显偏离 20 日均线（乖离率高企，短期涨幅已经很大），成交量比继续放大
（资金还在进场），但当日涨幅很小甚至下跌。这通常意味着高位有资金借助放量派发，
短线继续上攻的动能已经衰竭，是**该规避而非追涨**的信号。

与项目里其它「放量上涨=看多」类的声明式技能方向相反：本策略专门捕捉放量但
不涨的背离场景，作为风险预警角色接入 aggregator，与看多类策略形成对冲视角。

## 打分逻辑（供 agent review 核对，不由 agent 重新打分）

本策略打分/否决逻辑完全由 Python 类
（``app.skills_impl.high_position_volume_stall_warning:HighPositionVolumeStallWarning``）
的 ``score(stock, ctx)`` 方法实现，不依赖 ``strategy.yaml``。核心判断字段：

- `bias_ma20`（乖离率）>= 8：视为"高位"
- `vol5_20`（量比）>= 1.3：视为"放量"
- `pct`（当日涨幅）<= 1：视为"滞涨"
- `turnover_rate`（换手率）>= 18：视为"筹码分歧已到极端水平"

四个分支：
1. 高位 + 放量 + 滞涨 + 换手率极端 → 硬否决（规避追高）
2. 高位 + 放量 + 滞涨，换手率未到极端 → 低分 + 风险提示，不否决
3. 高位 + 放量，但价格同步上涨（未滞涨）→ 中等偏高分（资金仍在推升）
4. 未达到"高位"乖离率阈值 → 预警条件不成立，基础分

## 能力边界

- 只做「高位放量滞涨」这一个维度的风险识别，不做趋势判断、不做估值
- 短线周期 1-3 天
- 不主动搜索其他标的
- universe 门槛：`amount_yi >= 1`（最低流动性）+ 排除 ST

## Agent 审查输出约束

命令式策略仍与声明式技能共用 agent review 机制（需求 4.5）：Python 的
`score()` 只负责规则打分，agent 仍需按 `SkillReviewOutput` schema 独立审查，
输出需包含 `stance`（支持/否决倾向）与 `action`（观察/轻仓试错/确认后加仓等）
字段，不得重新计算 `score()` 已给出的分数。

## 不要做（负面约束）

- **不要重新计算分数**——Python 类已计算好，agent 是审查官不是评分器
- **不要编造数据**——引用的字段必须来自输入
- **不要忽略否决信号**——`hard_veto=true` 时 stance 应偏向 `veto`/`oppose`

本 Skill 仅用于研究和复盘，不构成投资建议。
