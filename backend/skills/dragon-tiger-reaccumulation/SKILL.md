# 龙虎榜涨停后整理再启动

研究目标：识别最近一个自然月曾上榜且出现收盘涨停的股票，检验上榜后的缩量整理、支撑保持与温和放量能否提高未来五个交易日的 WR 和 PF。

## 判断顺序

1. 候选范围包含主板、ChiNext、STAR 和北交所；按照当时的股票身份使用对应涨停幅度。
2. 龙虎榜事件日期严格早于信号日，最近一个自然月至少有一次收盘涨停。上榜日和涨停日可以不同。
3. 最近上榜后至少经过三个交易日。整理期间保持上榜日低点附近的价格支撑，近三日成交量相对上榜日收缩。
4. 信号当日涨幅介于 0.5% 与 6%，成交量恢复至整理期的 1.2 至 2.5 倍，收盘接近整理区间上沿。
5. 入场声明统一为 `next_open`，使用项目现有可成交性、费用、仓位与五日退出规则。

## 证据边界

龙虎榜汇总反映公开交易事件，无法据此识别最终持有人、实际持仓或操纵意图。描述使用“资金活动迹象”和“待验证的再启动信号”。多日榜与单日榜金额可能重叠，禁止累加为累计持仓。机构席位信息需要独立的 `top_inst` 证据。

所有特征由 `evaluator.py::build_context` 计算，随后使用 `strategy.yaml` 进行筛选和评分。日线缺失、停牌、价格序列存在除权不连续、历史身份缺失时均不生成交易信号。历史复核只读取信号日及以前的价格，龙虎榜只读取前一日及以前的事件。

## 状态

固定规则的三窗信号研究为 FALSIFIED，默认停用，未加入推荐预设。完整证据见 `output/dragon-tiger-reaccumulation-review-2026-09-21.json`。生产特征调用方必须提供同一套历史输入并调用本目录 evaluator，字段缺失时声明会拒绝生成信号。

本次研究没有完成全技能推荐流程、历史公告风险过滤和组合资金占用重放，不具备发布依据。后续需要新的席位级证据检验资金行为假设，禁止继续扫描本次整理阈值。
