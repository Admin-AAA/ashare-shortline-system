## 3. 闸门差异（显式记录）

`evaluate_challenger`（L-010）：W2/W3 = PRODUCTION；**W1 = FALSIFIED**——W1 累计收益 +497.1 → +291.0
（−206pp）触发"任一收益指标回退 ≤1pp"上限，即使 WR +4.6pp / PF +0.24 / MDD 从 −46.76 改善到 −12.73。

两条判据的差异：**用户口径要求 Σ>0；仓库闸门要求 Σ 不回退**。本轮的取舍是"以更少的笔数换取更高的单笔质量"：
W1 笔数从 792 降到 453（−43%），单笔均值 +0.6277 → +0.8082（+29%），累计为正且回撤缩小 73%。
该取舍与用户"提高收益率"的目标一致（风险调整后收益与回撤均显著改善），故按用户口径发布并在此留痕。

## 5. LIVE 监控（7 天回看清单）

1. **每日推荐数量**：闸门族会让日均输出下降 ~40%（W1 792→453 笔 / 244 天）；若某日 0 推荐且非冰点市，
   检查是否多闸门叠加过紧（可临时把 `high_chg20_veto` 放宽到 30 观察）。
2. **出场分布**：`trailing_stop_gap` 占比应高于 `stop_loss_hit`；若相反，说明 act0.8 未生效。
3. **7 日实测 WR/PF**：对比 W3 的 61.11% / 1.619；若 WR < 55% 且 MDD 恶化，回退默认版本到 7（v7）观察。
4. **换手/成交额被剔除比例**：若某日 >70% 候选被闸门剔除，说明当日池子整体过热——这本是设计意图，
   但需确认仍有 ≥1 张卡过线，避免"闸门导致空仓"被误读为系统故障。
