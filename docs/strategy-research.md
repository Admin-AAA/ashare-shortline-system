## §157 [短线] 放量不大涨后的「高成交量溢价」— 预注册（2026-10-24 23:55 CST 写定，结果出来前不改）
- 思路（Gervais–Kaniel–Mingelgrin 2001 high-volume return premium）：一只股票某天成交量突然放大到平时的好几倍，但价格没怎么动——说明有人在大量换手、关注度突然上升，而不是消息驱动的大涨大跌。学术上这类股票之后一段时间倾向跑赢。
- 去重：L-069/L-081/L-082/L-124 等测的是放量/换手作为现有策略选中池里的**过滤或排序特征**；§156 是题材龙头追涨；NR7、RSI2、涨停回调、首阴、恐慌反弹都是价格形态。**「成交量冲击 + 价格平稳」作为独立选股策略没测过**，也不是入场回避过滤、不追涨停。
