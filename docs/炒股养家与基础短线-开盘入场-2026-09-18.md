# 炒股养家与基础短线策略开盘入场（2026-09-18）

## 触发

最近 60 天共有 14 条推荐未触发目标买点。7 条已完成五个交易日观察，其中 6 条上涨，平均参考收益 +7.90%。这些推荐已经通过选股和排序，随后因为价格没有回到 `ideal_buy` 而失去成交机会。

## 策略规则

`chao-gu-yang-jia-skill` 与 `daily-stock-analysis-skill` 新增顶层 `default_entry_mode: next_open`。当其中一个策略是卡片最高分来源时，卡片使用下一交易日开盘价成交。其他策略继续使用各自的 `entry_mode`。

执行仍受 `execution_policy.v5` 管理：开盘相对推荐价上涨超过 6% 时拒绝成交，停牌、涨停封单、无有效价格等情况也不会成交。持有期、费用、止损和 trailing 规则保持 v5。

## 工程修改

- `strategy_runner.py` 支持策略顶层 `default_entry_mode`，setup 可以继续单独覆盖。
- `skill_loader.py` 校验顶层和 setup 的 `entry_mode`。
- `entry_policy.py` 新增 `execution_policy_for_entry_mode()`：出场、费用、仓位沿用当前执行版本，只按声明的入场方式替换 entry。
- `strategy_profile.py` 的策略回测档案改读策略声明的入场方式，策略页的单策略收益与生产成交口径一致。
- 两个策略的 manifest 与 YAML 版本更新到 `0.2.0`。
- `research_entry_mode_three_window.py` 使用生产成交模拟器生成三窗口指标、配对日 bootstrap 和发布判定。
