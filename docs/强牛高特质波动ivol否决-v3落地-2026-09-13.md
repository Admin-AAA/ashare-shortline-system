# 强牛 × 高特质波动（ivol20）横截面风险否决 —— production_selection v3 落地

日期：2026-09-13　对应教训：L-093　策略版本：production_selection v2 → **v3（默认）**

## 1. 要解决的问题

冠军基线 `champion_baseline_20260911_report.json` 显示现行 v2 选股在生产非对称出场口径下为负期望
（严格 n=9 avg −0.839% PF0.68；宽口径 n=368 avg −1.104% PF0.64），亏损集中在 `stop_loss_gap`
（隔夜跳空止损，−6~−7.4%），而赢家被 +6% 止盈/移动止盈截断。L-061~L-085 已系统性证伪几乎所有
日线横截面杠杆与外部择时门控，唯一稳健胜利 L-070 是"硬排除负期望单元"这类**负向否决**。本工作沿
同一合法方向，寻找一个可从日线严格自构、三窗口稳健、且未被既有研究覆盖的**横截面风险否决**。

## 2. 因子定义（T 收盘可得，无前视）

- 个股日收益 r = pct_chg/100；市场收益 m = 中证500（000905.SH）pct_chg/100，按交易日对齐。
- 20 日滚动回归：beta = Cov(r,m)/Var(m)（min_periods=16）；残差 e = r − beta·m；
  **ivol20 = Std(e) 的 20 日滚动标准差**，即剔除市场 beta 后的个股特质波动。
- 决策值 = ivol20 在**当日全市场横截面的 pct rank**（不用绝对阈值：全市场 80 分位跨日在
  0.0251~0.0449 漂移）。落库列 `daily_kbars.ivol20`，分位由 `app/services/risk_features.py` 现算。

## 3. 为什么是"强牛门控 + top20% 尾部"，而不是线性/一刀切

- 全市场三窗口五分位快筛：ivol20 Q5−Q1 三窗同负（−0.120/−0.245/−0.729），|IC| 最大 0.076；
  Q1→Q5 的"5 日内 ≤−5% 大亏率"三窗单调飙升（4.0%→22.9% / 13.9%→34.6% / 3.8%→25.6%），
  正对应生产跳空止损亏损源。
- **一刀切否决在 W1 有害**：强趋势牛市里高波动是领涨赢家；regime×ivol 交叉显示高 ivol 仅在
  **强牛** regime 三窗一致更差，弱势/偏多/震荡里反而更好（超跌反弹弹性）。
- 选中池内"不分 regime 的线性 IC/三分位"很弱且翻号（−0.026/+0.012/+0.056，见并行 L-084 廉价
  初筛）——这与本规则不矛盾：edge 在"强牛 × 极端 top20% 尾部 × 真实递补"，是条件化、非线性的。

## 4. 生产同构三窗口终审（真实生产代码，含自然递补）

## 5. 工程实现（生产/回测同源）

- 数据层：`daily_kbars` 增列 `ivol20`（model + ALTER）；`scripts/backfill_ivol20.py` 月分块幂等
  回填（已回填 2024-06 起 201.6 万行，与研究面板 corr≈1）；`backfill_daily_bars.py` 末尾增量补齐。
- 特征层：`app/services/risk_features.py`（compute_ivol20 / load_ivol20_pct_map / attach）。
- 决策层：`ProductionSelectionPolicy` 新增 3 字段（**默认 False，v1/v2 逐位不变**），
  `aggregator.apply_pool_rules` 在去重后、分数线前做"强牛 & pct≥0.80"硬剔（drop_owner=
  `strong_high_ivol_veto`），下一名自然递补；loader 放开 v3；`production_selection.v3.json`
  = v2 全部规则 + 开启本规则；**默认版本切到 v3**。
- 两选择咽喉同一 helper 附分位：live `services/runs/stages/adapters.py`、回测
  `services/backtest/policy_experiment.py`（规则关闭时不读库、零行为变化）。
- 测试：`tests/test_strong_high_ivol_veto.py`（8 项，含纯数学与强牛/非强牛/缺字段/v1v2 不变）。

## 6. 诚实残留弱点

1. W1 单窗配对 CI 下界 −0.012 微破 0；强证据来自三窗同向 + W2 CI 严格为正 + 合并/block bootstrap。
2. W3 仅 3–4 个改动日、n=10，单窗不显著。
3. 规则只在强牛生效（1826 选中卡约 587 为强牛），非强牛零影响。
4. 本地库 2025-02 前日线稀疏，冻结窗最前几周 ivol 覆盖低，缺字段卡保守不剔。
