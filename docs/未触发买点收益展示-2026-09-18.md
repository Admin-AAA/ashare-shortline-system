# 未触发买点（missed）也要看到收益率 — 复盘页补旁路参考口径（2026-09-18）

## 需求

复盘页里"未触发 / 未成交"的记录收益列是空的。这些票没有真实成交，不能进胜率与净收益口径，
但用户需要知道它们**买了会怎样**——否则无法回答"没买到是躲过亏损，还是错过盈利"。

## 口径设计（与「取消后 5 日观察」同构，只作旁路参考）

- 基准价：`recommend_price`（信号日参考价，也是 outcome 静态指标的基准）。
- 收益：`close_return − 附加成本 0.07%`，其中 `close_return` 是"按推荐价买入并持有到观察期末
  （第 `horizon_days=5` 个交易日）收盘"的静态收益。
- **完整性**：只有行情已覆盖满 `horizon_days` 个交易日的样本才给数值；未满的返回
  `pending` + 已观察天数，**绝不用被截断的窗口冒充"持有到期"**（与 `build_cancel_observations`
  对 5 日窗口的处理一致）。
- 不进 `trade_count / win_rate / total_net_return`；只出现在独立字段里。

## 首次读数（近 60 天，2026-07-21 ~ 2026-09-18，cohort `recon-v1-e50c3707…`）

```
missed_count 14 / observed_count 7 / pending_count 7
average_reference_return +7.90%
avoided_loss_rate 14.3%（只有 1/7 笔"如果买了会亏"）
missed_gain_count 6
```

逐笔样本（`002815`，2026-09-04 推荐价 14.55）：信号日之后一路向上、从未回到买点，
第 5 个交易日（09-11）收 20.08 = 相对推荐价 **+38.01%**（净参考 +37.94%）。
即"未触发"里有相当一部分是**错过盈利**，不是躲过亏损。

**边界说明**：这是静态旁路数字（无止损、无 trailing、假设按推荐价成交），不等于真实可实现收益；
要据此改入场规则必须走 path A 三窗验证（L-018），不能拿这个数字直接改参数。
