# 动态退出利润地板生产切换 Spec

## 目标

把旧的“前高回撤 0.8%”移动止盈替换为严格因果、给正常波动留空间的利润地板，
在不恶化最大单笔亏损的前提下，提高平均净收益、利润因子和逐笔 Sharpe，并降低每笔交易承担的下行损失。

## 冻结策略

- 固定硬止损与固定止盈保持不变。
- 入场日禁止卖出；只用入场日收盘生成次日计划。
- 前一交易日已知最高浮盈达到 2% 后激活。
- 生产利润地板锁住前一日最高浮盈的 50%。
- 最低保护收益为 0.3%，用于覆盖滑点和交易成本后保留小幅净利润。
- 当日新高只能更新下一交易日保护价。
- 保护价只能上移，不能下调。
- 开盘跌穿保护价按开盘成交，标记 `trailing_stop_gap`；盘中触及标记 `trailing_stop_hit`。
- 历史两轮扫描仅保留为有未来信息的对照上界，不再作为生产默认退出。

## 候选与切分

候选在打开验证段前固定为 25% 与 50% 两档利润锁定比例，不再增加候选。

- 开发段：前 14 个唯一交易日，153 笔，2026-05-12 至 2026-07-07。
- 冻结验证段：后 7 个唯一交易日，143 笔，2026-07-08 至 2026-07-23。
- 同一交易日不得跨段。
- 开发段仅在通过门槛的候选中按平均净收益、利润因子选择；最终选择 50%。

## 生产门槛

旧“平均盈利 / 平均亏损”会忽略胜率，并在策略把轻亏单转成盈利后产生样本迁移偏差。
生产切换改用能够反映组合期望与总损益的指标：

- 平均净收益不低于纯固定因果基线。
- 逐笔 Sharpe 不低于基线。
- 利润因子（总盈利 / 总亏损绝对值）不低于基线。
- 每笔预期下行损失（总亏损绝对值 / 全部交易数）不高于基线。
- 胜率下降不超过 2 个百分点。
- 最大单笔亏损不得恶化超过 0.3 个百分点。
- 开发段、冻结验证段、全样本必须全部通过。

## 结论

50% 利润地板在开发段、冻结验证段和全样本均通过生产门槛。
生产 `_resolve_exit` 切换为单路径因果利润地板；历史两轮扫描改名保留，只用于有偏上界对照。

该结果不等于未来收益保证。上线后应持续按新增正式样本监控平均净收益、利润因子、每笔预期下行损失、
最大亏损和退出原因分布，不得根据同一批历史样本继续调参。
