# 自适应共识闸门（尾随边际逐日切换选股政策）— 2026-09-16（第 24 轮）

## 0. 本轮解决的问题

第 23 轮确认：`≥3 背书`是 W1/W2 的强正信号、W3 的强负信号，且**当日可观测**的任何特征
（market base × sentiment、涨停家数、中位 ivol、≥3 与 <3 的当日分数差）都无法把它切开——
同一个桶在 W1/W2 为正、在 W3 为负。唯一可用的是**已结算的近期表现**。

本轮把该统计量做成逐日政策切换，端到端跑三窗。**结果：W1、W3 首次同时达标。**

## 1. 门控统计量（严格因果）

```
edge(t) = mean(net | 该笔卡的背书数 ≥3) − mean(net | 背书数 <3)     # 只用 t 之前已结算的成交
```

- 窗口：最近 K=15 个交易日；样本任一侧 <5 笔 → 不施加（保守 = 与默认一致）。
- 分布：W3 的 edge 全部为负（23 天，p90 = −1.58，中位 −2.33）；W1 中位 +0.28；W2 中位 +1.31。
  → 该统计量能识别 W3 段，但对 W1/W2 的区分是概率性的（W1 有 26–43% 的天数为负）。

## 2. 三态门控（V2 夹具）

| 条件 | 使用的政策 | 含义 |
|---|---|---|
| `edge > 0` | v14 = 换手<8 + **≥3 背书** | 多策略共振是正信号 → 只买共振票 |
| `edge < −1.5` | v13 = **≤2 背书** | 共振是负信号 → 只买弱共识票 |

触发分布：W1 122/59/54 天、W2 84/19/25 天、**W3 0/21/9 天**。
