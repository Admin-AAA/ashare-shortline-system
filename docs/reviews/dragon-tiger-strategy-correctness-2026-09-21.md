# 龙虎榜策略正确性审查

## 判定

“最近一个自然月上榜且涨停”可以定义观察范围。现有股票级龙虎榜和日线数据无法确认同一参与者持续持仓，也无法确认其交易意图。本次预注册的“上榜后缩量整理、支撑保持、温和放量”交易规则未达到验收要求，研究状态为 FALSIFIED。

## 假设与检验

待验证假设：上榜与涨停提供历史关注事件；随后卖出压力减小、支撑保持，信号日量能恢复，可能增加 T+1 后的上涨概率并改善 WR 和 PF。

固定条件来自 `backend/skills/dragon-tiger-reaccumulation/strategy.yaml`，本次只检验一组条件。每个交易日按 `aggregate()` 生成的 `final_score` 选择最多六只；同一股票、同一最近上榜事件只选择一次。信号日使用当日收盘数据，龙虎榜严格使用信号日之前的数据。下一交易日使用声明的 `next_open`，退出与费用通过生产 `_simulate_outcome`，仓位通过 `_resolve_position_size`。

对照组来自同一个历史候选范围，使用同样的评分与执行方式，取消整理 setup 的必要条件。对照组用于检验本次形态假设，未代表现有生产推荐策略。

## 逻辑限制

1. 上榜原因包含涨幅、跌幅、换手异常及多日累计事件。仅有上榜记录无法解释买入方向。例：2025-02-05 的 600789 命中候选，其最近事件为三日跌幅上榜。
2. 缩量和守住低点可以出现在多种交易情形中，无法单凭这两个条件确认持仓集中或新增买入。
3. 数据表按股票和日期保存唯一记录。`state_adapters.py` 遇到同日多种原因时合并原因文字，金额保留第一条，因此金额与事件区间的关系无法完整还原。
4. 本地 `dragon_tiger` 没有席位身份。`fetch_top_inst` 虽有接口函数，席位明细尚未进入本次历史研究输入。营业部身份本身也只提供交易渠道证据。
5. 捕捉后续上涨必须同时检查可成交性。2026-08-05 的 000506 后续达到上涨标签，实际入场被 `gap_up_blocked` 拒绝。

## 数据与指标范围

- W1/W2/W3 日期分别为 2025-01-15 至 2026-01-16、2026-01-17 至 2026-07-30、2026-08-01 至 2026-09-18。数据库交易日数量为 244/128/35，W3 的指定日期范围包含 35 个交易日。
- 龙虎榜数据起始日为 2025-01-02，W1 起点之前不足完整自然月。窗口起点的数据准备不满足完整发布证据要求。
- 本次是独立策略信号研究，没有完成全技能端到端推荐重放；历史公告、新闻、席位身份、分钟成交数据尚未接入该脚本。
- JSON 中的 `max_drawdown_pct` 是按信号日平均收益累加曲线计算的回撤，可低于 -100%；它不能解释为账户净值回撤。
- `capital_utilization_pct` 是已结算信号分配仓位之和除以全部选中信号数；它未计算同时持有多只股票的组合资金占用。
- `coverage_pct` 是已结算笔数除以选中信号数，另报交易日覆盖率。W3 有两笔已入场记录尚未完成结算，四笔未成交。
- 这些限制使本次结果只能支持拒绝当前规则发布，不能作为对所有龙虎榜策略的否定。

## 后续研究所需证据

资金行为假设需要保留股票、日期、上榜原因、统计区间、席位名称、买卖方向、买卖金额和发布时间。必须区分单日榜与多日榜，识别同一席位跨事件的重复参与；未上榜期间的持仓变化保持未知。比较应在同一信号日和板块内进行，并包含全部符合条件的股票及未成交样本。

本次整理条件停止扫描。席位级数据能够提供新的独立证据后，可以提出新的时间序列假设，并重新执行三窗检验。
