## 安全结论

MySQL 测试锁的先前持有连接在验证时已不再出现在 `information_schema.PROCESSLIST`，因此未发送 `KILL`，以避免 MySQL connection ID 复用导致误杀。所有本次观察命令均为只读，除 migration runner 的既有 ledger no-op 校验外未写业务数据。
